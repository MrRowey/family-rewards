# Family Rewards Website

Independent public website and documentation. Never merge application branches into gh-pages.

## Development
Use Node.js 22 or later. Run `npm install`, `npm run dev`, `npm run check`, and `npm run build`. Preview with `npm run preview`.

GitHub Pages: select GitHub Actions in Settings > Pages. The workflow builds on pushes to gh-pages. Content is provisional until verified against the release. Use fictional family data only.
